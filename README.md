Генератор паролей на Python

Описание проекта

«Генератор паролей» — приложение на языке Python с графическим интерфейсом, предназначенное для создания случайных паролей.

Возможности программы

Генерация паролей длиной от 4 до 50 символов.

Использование латинских букв верхнего и нижнего регистра.

Использование цифр от 0 до 9.

Проверка корректности введённой длины.

Отображение готового пароля в окне программы.

Используемые технологии

Python

Tkinter

PyCharm

Git и GitHub

Запуск программы

Установить Python.

Скачать или клонировать репозиторий проекта.

Открыть папку проекта в PyCharm.

Запустить основной файл программы.

Дополнительные библиотеки устанавливать не требуется, так как используются стандартные модули Python.
